# 분당 당근 ROCK 페스티벌

모바일 최적화 정적 웹앱입니다.

## 일본어 가사 표시
일본어 곡은 각 구간을 다음 순서로 표시합니다.

1. 일본어 원문
2. 한글 발음
3. 한국어 의미

## Vercel
이 저장소를 Vercel에서 Import하면 별도의 빌드 명령 없이 바로 배포할 수 있습니다.
`index.html`이 사이트 진입점입니다.

> 현재 응원글과 Open Mic 투표는 브라우저 localStorage에 저장되므로,
> 관객 사이의 실시간 공유가 필요하면 다음 단계에서 Supabase/Firebase 연결이 필요합니다.
